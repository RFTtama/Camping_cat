# 🏕️ Camping_cat

天気と時間に合わせて、猫が同じ場所でキャンプをする様子を眺めるアプリです。

ユーザーの現在地から天気情報を取得し、その日の天候に応じて猫の行動やキャンプサイトの様子が変化します。

「ゲームを遊ぶ」というよりも、**そこに住んでいる小さな猫を眺める**ようなアプリを目指しています。

---

## 🌤️ コンセプト

Camping_catでは、現実世界の時間や天気とゲーム内の世界を連動させます。

例えば、

* ☀️ 晴れ → 外を散歩する
* 🌧️ 雨 → 雨の中を散歩したり、テントで過ごす
* 🌙 夜 → 焚き火のそばで過ごす
* ⛺ 時間の経過 → キャンプサイトの様子が変化する

といったように、時間が経つことで猫の生活にも変化が生まれます。

---

## 🏗️ アーキテクチャ

基本的には **Model / Controller / View** の構成を採用しています。

```text
                ┌─────────────┐
                │    Model    │
                │             │
                │ 天気・状態  │
                │ 行動決定    │
                └──────┬──────┘
                       │
                       ▼
                ┌─────────────┐
                │ Controller  │
                │             │
                │ 定期的に    │
                │ 指示を送る  │
                └──────┬──────┘
                       │
                       ▼
                ┌─────────────┐
                │     View    │
                │             │
                │ StateMachine│
                └──────┬──────┘
                       │
                       |
                       ▼
                  子オブジェクト
```

Controllerは一定間隔でModelから現在の行動を取得し、Viewへ指示を送ります。

---

## 🐈 キャラクター

キャラクターはシンプルなピクセルアート / 2Dグラフィックを使用する予定です。

多くの状態・アニメーションを用意する必要があるため、複雑なパーツ分けよりも、画像の差し替えや簡単な位置・揺れの変化を利用した表現を検討しています。

例えば歩行では、複数の画像を切り替えながらキャラクターの位置を移動させることで、シンプルなアニメーションを実現する予定です。

---

## 🌄 背景

背景にはパララックスを利用した自然風景を使用する予定です。

時間帯に応じて、

```text
☀️ Day
   ↓
🌅 Dusk
   ↓
🌙 Night
```

のように背景を変化させ、同じキャンプサイトでも時間の経過を感じられるようにします。
